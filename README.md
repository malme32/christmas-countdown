# Pacman Web App

A browser-based Pacman game.

> Status: repository scaffold. No game code is present yet.

## Overview

This repository will host the Pacman web app: a static, browser-delivered
Pacman game. It is container-friendly and intended to be served as static
assets.

## Getting started

The app is not implemented yet. Once the source lands it is expected to run as
a static site:

```sh
# placeholder — update when the source is added
python3 -m http.server 8000
```

Then open http://localhost:8000.
